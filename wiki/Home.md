## 📋 About This Project

This repository demonstrates a microservice-based sample application deployed to Azure Container Apps. The solution showcases:

- **Microservices Architecture** - Three independent services working together
- **Dapr Integration** - State management and service-to-service communication
- **Container Apps** - Managed serverless container platform
- **KEDA Autoscaling** - Event-driven autoscaling capabilities
- **CI/CD with GitHub Actions** - Automated build and deployment
- **Infrastructure as Code** - Bicep templates for Azure resources

## 💡 Use Cases

This sample is perfect for:
- Learning microservices architecture on Azure
- Understanding Dapr and its building blocks
- Implementing CI/CD pipelines for containerized applications
- Exploring Azure Container Apps capabilities
- Building production-ready microservices solutions
